ATYou Website

First-year group web development project · Technologies: HTML, CSS, JS

About the project

This is a first-year web development group project. ATYou was created to help first-year students entering third-level education. The website contains tips, advice and resources to help first-year ATU students settle in, find their way and thrive. Its design is colourful and inviting. Some parts of the site, such as the news and blog sections, are placeholders. The website is best viewed on desktop.

My role: I created the logo, the map assets, and the text for certain pages.

Technologies used: HTML, CSS, JS
